# 注意力熵

[English](../../algorithms/attention-entropy.md) | 简体中文

已实现的多尺度方法：**MAttEn**。

## 定义

注意力熵描述局部极值出现的时间关系。它建立相邻极大值、相邻极小值以及交替极大值和极小值之间的间隔序列，再衡量各序列的分布。

## 核心步骤

在每个尺度上：

1. 构造一条标准粗粒化序列。
2. 检测严格局部极大值和极小值。
3. 建立四种间隔序列：极大值到极大值、极小值到极小值、极大值到极小值，以及极小值到极大值。
4. 估计每种序列的直方图分布并计算 Shannon 熵。
5. 平均四个熵值：

```math
H_{\mathrm{Att}}
=
\frac{H_{XX}+H_{NN}+H_{XN}+H_{NX}}{4}.
```

## 参数含义

- `scale`：请求的最大标准多尺度尺度。

MAttEn 没有嵌入维数或幅值阈值。粗粒化后必须仍能检测到严格局部极大值和极小值，因此单调、恒定或几乎没有特征的序列可能不适用。

## 结果

MAttEn 返回 `scale` 个值。每个值概括该尺度上四种极值间隔分布的均匀程度。比较信号时，应保持采样方式、片段长度、预处理和尺度范围一致。
