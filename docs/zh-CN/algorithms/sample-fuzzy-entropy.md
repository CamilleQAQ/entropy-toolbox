# 样本熵与模糊熵

[English](../../algorithms/sample-fuzzy-entropy.md) | 简体中文

已实现的多尺度方法：**MSE** 和 **MFE**。

## 定义

样本熵和模糊熵比较长度为 `m` 与 `m + 1` 的延迟模板。MSE 统计 Chebyshev 距离小于硬阈值的模板对；MFE 则用连续的模糊隶属度代替硬判定。

## 核心步骤

首先对完整输入信号进行一次标准化。在每个尺度上，将标准粗粒化序列划分为延迟模板。对于 Chebyshev 距离为 `d` 的两个模板，MSE 使用匹配规则

```math
d < r.
```

MFE 使用模糊隶属度

```math
\mu(d)=\exp\!\left(-\frac{d^n}{r}\right).
```

设 `P_m` 和 `P_{m+1}` 分别表示维数 `m` 与 `m + 1` 下得到的平均匹配量，两种方法均计算

```math
H=\ln\!\left(\frac{P_m}{P_{m+1}}\right).
```

随后对每个尺度的一条标准粗粒化序列重复计算。

## 参数含义

- `m`：模板维数。
- `r`：标准化信号上的正相似度容差。
- `n`：仅供 MFE 使用的正模糊隶属度指数。
- `tau`：模板样本之间的延迟，单位为样本点。
- `scale`：请求的最大标准多尺度尺度。

## 结果

MSE 和 MFE 返回 `scale` 个值。数值越大，表示在所选方法和参数下，模板维数增加后匹配更不容易出现。由于相似度规则不同，MSE 与 MFE 的结果不能直接互换。
