# 参数与数据准备

[English](../parameters.md) | 简体中文

参数选择是科学方法的一部分。工具箱会拒绝高层接口中明显无效的输入，但无法判断哪些有效设置适合某个具体数据集。

各参数在估计器中的数学作用见[算法手册](algorithms/index.md)。

## 参数速查

| 参数 | 含义 | 高层接口要求 | 使用说明 |
|---|---|---|---|
| `m` | 嵌入维数 | 不小于 2 的整数 | 数值越大，可能的模式越多，通常也需要更多数据。 |
| `nc` | 离散类别数 | 不小于 2 的整数 | 散布模式总数随 `nc` 和 `m` 快速增长。 |
| `tau` | 嵌入样本之间的延迟，单位为样本点 | 不小于 1 的整数 | `tau=1` 表示相邻样本，不是 1 秒；应结合采样率解释。 |
| `scale` | 普通或复合多尺度的最大尺度 | 不小于 1 的整数 | 返回数组包含尺度 `1..scale`；尺度越大，粗粒化后信号越短。 |
| `kmax` | 时间移位方法的最大尺度 | 不小于 1 的整数 | 返回的 TSM 数组包含尺度 `1..kmax`。 |
| `delta` | 斜率熵的下阈值 | 不小于 0 的有限数 | 单位与预处理后信号的差分相同。 |
| `gamma` | 斜率熵的上阈值 | 不小于 `delta` 的有限数 | 兼容实现过去将参数拼作 `gama`；高层接口兼容两种拼写。 |
| `r` | MSE 和 MFE 的相似度容差 | 大于 0 的有限数 | 多尺度实现会在粗粒化前对完整输入信号标准化，因此 `r` 在标准化后的尺度上解释。 |
| `n` | MFE 的模糊隶属度指数 | 大于 0 的有限数 | 控制模糊相似度随模板距离增大而衰减的速度。 |
| `type_` | 部分模糊散布方法保留的映射分支 | 可选，默认 `0` | 除非复现实验明确指定其他受支持值，否则保留默认值。 |

本仓库示例常使用 `m=3`、`nc=6` 和 `tau=1` 作为起点，但它们不是通用推荐值。

## 信号长度与最大尺度

普通粗粒化会缩短信号。长度为 `N` 的输入在尺度 `s` 上大约只剩 `floor(N / s)` 个样本。随后，嵌入维数为 `m`、延迟为 `tau` 的窗口需要跨越 `(m - 1) * tau` 个位置。

例如，一段 2,000 点的信号在尺度 20 上大约只剩 100 个粗粒化样本。增大最大尺度、嵌入维数或延迟，都会减少可用模式的数量。即使程序能够完成计算，模式数量过少时，其统计可靠性仍可能很弱。

高层接口会拒绝在最大请求尺度上连一个完整嵌入窗口都无法形成的设置，但这并不等于保证统计可靠。不存在适用于所有方法和信号的统一最小长度。
MAttEn 没有嵌入维数，但要求粗粒化后的信号仍包含足够的局部极值。即使通过长度检查，某个尺度变得单调或几乎没有特征时仍可能不适用。

确定最大尺度前，应当：

1. 计算该尺度下的有效信号长度。
2. 考虑模式空间大小，尤其是 `nc**m`。
3. 判断熵曲线末端是否仍有足够模式支撑目标分析。
4. 对待比较样本使用相同的片段长度和尺度范围。

## 预处理

工具箱不会自动去趋势、滤波、重采样、归一化、标准化，也不会自动把长记录切分成窗口。这些选择可能改变结果的科学含义。

同一次比较中的所有信号应使用同一套、有记录的预处理流程。至少记录：

- 原始采样率以及是否重采样；
- 窗口长度和重叠；
- 去趋势或滤波操作；
- 幅值归一化或标准化；
- 缺失值和无限值的处理方式；
- 熵方法及其全部参数。

不要笼统规定所有信号都必须标准化。序数方法和幅值方法对变换的响应不同。尤其是 `delta` 和 `gamma` 是差分阈值：缩放信号却不调整阈值，会改变符号化结果。

## NaN 与无限值

高层接口 `msentropy.compute` 会拒绝包含 `NaN`、正无穷或负无穷的信号。它不会擅自决定应删除缺失点、插值，还是在该位置分段。

准备数据时可以显式检查：

```python
if not np.isfinite(x).all():
    raise ValueError("Decide how to handle missing or infinite samples first")
```

低层兼容函数保留经过验证的历史行为。不同算法可能返回非有限值，或抛出各自的错误。这对复现有用，但不能视为自动处理缺失数据。

## 比较结果

合理的比较包括：

- 对经过相同处理、长度一致的信号片段使用同一方法和同一组参数；
- 观察同一种方法随尺度变化的曲线；
- 通过明确的下游指标或验证实验比较多种方法。

不要假设 MPE、MDE、MFuDE 等不同方法族的原始熵值处于同一个数值尺度。某个方法得到更大的值，并不代表它一定检测到了更多物理复杂性。改变 `m`、`nc`、`tau`、阈值或预处理，也可能改变结果的含义和范围。

为保证可复现性，应报告方法名、软件包版本、全部参数、输入片段长度、采样率和预处理方式。
